# BookingBee.ai — Home page

The project uses React, TypeScript, Tailwind CSS v4, shadcn/ui and Vite.

## Live site
Published on GitHub Pages — integrations page: `#/integrations`.

## Just want to see it?
Double-click **`index.html`**. It's the finished build and opens straight from Finder, with no server needed.
Keep it next to the `public` folder, because that's where the images live.

## Editing it
You need Node.js 20.19 or newer. Download it from https://nodejs.org if `node -v` shows an older version.

```bash
cd bookingbee-homepage
npm install        # first time only
npm run dev        # live preview (opens http://localhost:5173/app.html, reloads as you edit)
npm run build      # type-checks, then rebuilds index.html
```

## Where things live
| Path | What it is |
|---|---|
| `index.html` | The built site. Generated by `npm run build`, so don't edit it by hand |
| `app.html` | Source entry used by the dev server |
| `src/App.tsx` | Page markup (every section, in order) |
| `src/site.css` | Page styles (ported 1:1 from Figma) |
| `src/index.css` | Tailwind + shadcn theme tokens (BookingBee colours) |
| `src/interactions.js` | Menus, demo form, accordion, FAQ, stories, before/after slider, counters |
| `components/ui/globe-feature-section.tsx` | The globe component (unchanged) |
| `components/ui/bookingbee-globe.tsx` | BookingBee-themed globe used in the Trusted section |
| `components/ui/button.tsx`, `lib/utils.ts` | shadcn Button + `cn()` helper |
| `components.json` | shadcn config: new components install to `components/ui` |
| `public/assets`, `public/fonts` | Images and fonts |

Add more shadcn components with `npx shadcn@latest add <name>`. They land in `components/ui`, the folder every shadcn component imports from (for example `@/components/ui/button`). That's why the folder must stay at that path.

`cobe` is pinned to 0.6.x on purpose. cobe 2.x dropped the `onRender` option the globe needs to spin.
